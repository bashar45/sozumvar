# Sözüm Var — sozumvar.online

WhatsApp üzerinden yürüyen 21 günlük alışkanlık ve kimlik koçluğu programının tanıtım sayfası.

Statik HTML/CSS, derleme adımı yok. Coolify bu repoyu `Dockerfile` ile `nginx:alpine` üzerinde yayınlar (port 80).

- `index.html` — tanıtım sayfası
- `gizlilik.html`, `veri-silme.html` — yasal sayfalar
- `fonts/` — yerel fontlar (Google Fonts kullanılmaz)
- `img/` — CC0 görseller, kaynaklar `img/KAYNAKLAR.txt`
